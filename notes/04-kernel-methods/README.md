# Kernel Methods

This folder contains the classical non-linear learning track built around kernel
geometry and regularized function classes.

## Recommended Order

1. `kernel_functions.md`
2. `kernel.txt`

## Focus

- kernels as implicit inner products
- Gram matrices and valid kernels
- RKHS and regularization intuition
- kernel ridge regression, SVM, SVR, and sparse kernel-style formulations
